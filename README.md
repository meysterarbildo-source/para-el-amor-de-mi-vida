# Para el amor de mi vida

Página romántica de Ariana y Meyster, publicada con GitHub Pages.

- `index.html`: página pública.
- `admin-recuerdos.html`: panel protegido por Supabase Auth.
- `supabase-public-gallery.js`: carga solo medios publicados.
- `supabase-setup.sql`: tabla, Storage y políticas RLS.
- `GUIA-SUPABASE.md`: configuración de Supabase.

Antes de usar el panel hay que ejecutar el SQL y reemplazar `PEGA_AQUI_TU_ANON_KEY` por la anon/publishable key del proyecto Supabase.
